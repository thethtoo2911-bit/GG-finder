# GG Finder MVP - Project Charter

## 1. Project Title

**GG Finder - Nearby Gamer Finder**

## 2. Project Overview

GG Finder is an MVP application designed to help gamers find other gamers nearby who are available to play together.

The MVP focuses on three main activities:

1. Browsing nearby gamers within a 5 km radius.
2. Viewing a gamer's profile and gaming information.
3. Sending a squad request to invite another gamer to play.

## 3. Problem Statement

Gamers can have difficulty finding suitable teammates who play the same game and are available to play.

GG Finder addresses this problem by providing a simple platform where users can discover nearby gamers based on their location, game, skill level, and availability.

## 4. Project Objectives

The objectives of the GG Finder MVP are to:

- Allow users to discover gamers within 5 km.
- Display useful information about nearby gamers.
- Allow users to view detailed gamer profiles.
- Allow users to send squad requests.
- Store gamer profiles and squad requests in a database.
- Provide a simple and easy-to-use user experience.

## 5. Target Users

The target users are:

- Gamers looking for nearby teammates.
- Players who want to find people who play the same game.
- Gamers who want to check another player's rank, role, and availability before inviting them.

## 6. Main Features

### 6.1 Browse Nearby Gamers

Users can see a list of gamers located within 5 km.

Each gamer displays:

- Username
- Main game
- Rank/skill level
- Online status: Available or Busy

### 6.2 View Gamer Profile

Users can select a gamer to view their profile.

The profile includes:

- Username
- Main game
- Rank/skill level
- Preferred role/character
- Win rate (optional)
- Online status

### 6.3 Send Squad Request

Users can send a squad request to another gamer to invite them to play together.

Requests can have the following statuses:

- Pending
- Accepted
- Rejected

## 7. MVP Scope

### In Scope

- Gamer profiles
- Main game information
- Rank/skill level
- Preferred role/character
- Optional win rate
- Online status
- Gamer location
- Nearby gamer discovery within 5 km
- Gamer profile viewing
- Squad requests
- Database storage

### Out of Scope

- In-app voice chat
- In-app messaging
- Game streaming
- Tournament management
- Payment system
- Advanced matchmaking algorithms

## 8. Project Deliverables

The project deliverables are:

- Working GG Finder MVP
- Project Charter
- Requirements Specification
- Acceptance Criteria
- Database Design
- Source code
- Public GitHub repository

## 9. Success Criteria

The MVP will be considered successful when a user can:

1. Browse gamers within 5 km.
2. See each gamer's basic information.
3. Open a gamer's profile.
4. View the gamer's gaming information.
5. Send a squad request.
6. Store and retrieve the relevant information correctly.

## 10. Project Constraints

- The application is limited to MVP functionality.
- Nearby gamer discovery uses a 5 km default radius.
- Gamer and squad request information must be stored in a database.
- The project source code and documentation must be publicly accessible on GitHub.
